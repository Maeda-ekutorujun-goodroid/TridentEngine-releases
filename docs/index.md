# TridentEngine ドキュメント

TridentEngineの使い方を機能別にまとめています。
はじめての方は入門チュートリアルからどうぞ。
各機能ページは冒頭の「**1分でためす**」でコピペで動く最小サンプルから始まり、
末尾の「**よくあるつまずき**」で動かないときの確認ポイントをまとめています。

| [入門チュートリアル](getting-started.md) | プロジェクト作成からエクスポートまで30分で体験 |
| [プロジェクト管理とビルド](project.md) | Trident Hub、プロジェクト設定、エクスポート、ビルド方法 |
